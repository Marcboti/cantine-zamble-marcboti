# La caisse de la cantine de djahakro

## Description

Ce mini-projet JavaScript simule la caisse de la cantine. Il traite une commande à la fois : le programme identifie le plat grâce à son code, calcule le montant à payer selon la quantité commandée et affiche un récapitulatif dans le terminal.
Il indique également la monnaie à rendre lorsque le montant versé est suffisant, ou le montant manquant dans le cas contraire.

## Plats proposés
| Code | Plat | Prix unitaire |
|---|---|---:|
| 1 | Attiéké-poisson | 1 500 FCFA |
| 2 | Riz-poulet | 2 000 FCFA |
| 3 | Alloco-œuf | 1 000 FCFA |

## Fichiers du projet
- `cantine.js` : code du programme et données de la commande.
- `preuves.txt` : données, commande exécutée et sorties des trois tests demandés.
